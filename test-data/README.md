# Reader contract fixtures

These small files are generated by the Rust integration test
`shared_lod_contract_and_legacy_interoperability` and read by the JavaScript
integration tests. They contain two LineStrings with IDs 0 and 1. ID 0 enters
at resolution 8; ID 1 enters at resolution 1. Coordinates are deliberately
chosen so quantization changes the overview bounds.

- `refinement.parquet`: producer output with geo.lod, with bbox PageIndexes. The final
  two levels share a row-group boundary and use different LoDs. Overview integers
  use `BYTE_STREAM_SPLIT` with ZSTD compression.
- `refinement-delta.parquet`: the previous writer's `DELTA_BINARY_PACKED`
  version of the same data, retained for backward-compatible reads. It is not
  regenerated by the current writer.
- `shared.parquet`: geo.lod with an additional resolution-4 level referencing `l1`
  on RG 0; resolution 1 also references `l1` through RG 1. No bbox ColumnIndexes.
- `legacy.parquet`: geo.lod with distinct row-group boundaries, without bbox
  ColumnIndexes. This and `shared.parquet` are metadata-rewrite fixtures using
  dictionary encoding, independent of the production writer's encoding policy.

Regenerate explicitly from the repository root:

```sh
COGP_TEST_FIXTURE_DIR="$PWD/test-data" cargo test -p cogp --test end_to_end shared_lod_contract_and_legacy_interoperability
```

Normal test runs write only to temporary directories.

`base-covering.parquet` and `base-no-covering.parquet` exercise ordinary attributes
named `overviews`, independent bbox roots, and missing statistics/covering.
Regenerate all fixtures with:

```sh
COGP_TEST_FIXTURE_DIR="$PWD/test-data" cargo test -p cogp --test end_to_end
```

`attribute-encodings.parquet` covers dictionary-free `PLAIN` attribute encoding
and `BYTE_STREAM_SPLIT` overview integers with ZSTD compression, including nested nullable values, integer extremes, floats,
strings, and binary. Rust verifies all original values after conversion; JS
checks decoding of the same fixture. Regenerate it with:

```sh
COGP_TEST_FIXTURE_DIR="$PWD/test-data" cargo test -p cogp --test end_to_end attribute_encodings_preserve_values_and_nested_paths
```
